# 09: Manage app startup from the launch menu

Status: ready-for-agent
Type: task
Blocked by: 02

## What to build

Select verified app sign-in entries from the launch menu, confirm the changes, and restore the saved prior settings using the same workflow.

## Acceptance criteria

- [ ] Show allowlisted, verified entries and distinguish changes to the current user's sign-in from other startup mechanisms.
- [ ] Preview the exact entries to disable or restore in the combined plan. Confirmation applies only the selected changes.
- [ ] Restore prior entries using the existing app startup preferences. Keep automatic preference enforcement independently configurable.
- [ ] Verify selection, cancellation, disable, and restore with safe test entries.
