# Triage labels

Use the local status value in the ticket’s `Status:` line when a skill refers to a triage role.

| Triage role       | Local status      | Meaning                                     |
| ----------------- | ----------------- | ------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Awaiting maintainer evaluation              |
| `needs-info`      | `needs-info`      | Awaiting more information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent      |
| `ready-for-human` | `ready-for-human` | Requires human implementation               |
| `wontfix`         | `wontfix`         | Closed without planned work                 |
