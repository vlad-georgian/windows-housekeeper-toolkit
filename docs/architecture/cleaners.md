# Cleaner catalog

The registry instantiates cleaners with the resolved Windows paths. Each
cleaner defines an ID for `--app` and proposes candidates from known locations
or verified installations. Filesystem cleaners share the base removal method.
Cleaners with release or driver rules perform additional checks before removal.

| File                                                                                              | Responsibility                                                                                                                                |
| ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| [`index.ts`](../../src/cleaners/index.ts)                                                         | Registers the cleaners and sets their order in the menu.                                                                                      |
| [`base-cleaner.ts`](../../src/cleaners/base-cleaner.ts)                                           | Implements common filesystem removal.                                                                                                         |
| [`helpers.ts`](../../src/cleaners/helpers.ts)                                                     | Detects named caches, updater downloads, and old Squirrel versions, and rechecks Squirrel version selection before removal.                   |
| [`amd-installer-cleaner.ts`](../../src/cleaners/amd-installer-cleaner.ts)                         | Finds known AMD chipset installer extractions.                                                                                                |
| [`balena-etcher-cleaner.ts`](../../src/cleaners/balena-etcher-cleaner.ts)                         | Finds obsolete balenaEtcher Squirrel versions and updater payloads.                                                                           |
| [`chatbox-cleaner.ts`](../../src/cleaners/chatbox-cleaner.ts)                                     | Finds installers in the Chatbox self-update cache.                                                                                            |
| [`claude-code-cleaner.ts`](../../src/cleaners/claude-code-cleaner.ts)                             | Finds superseded native Claude Code binaries and regenerable cache data, and rechecks the current version before removal.                     |
| [`claude-desktop-cleaner.ts`](../../src/cleaners/claude-desktop-cleaner.ts)                       | Finds Chromium caches in the verified Claude Desktop package profile.                                                                         |
| [`codex-cleaner.ts`](../../src/cleaners/codex-cleaner.ts)                                         | Finds regenerable Codex caches and delegates release and npm residue handling.                                                                |
| [`codex-installations.ts`](../../src/cleaners/codex-installations.ts)                             | Detects inactive releases and interrupted npm update residue. It checks running binaries and holds the installer lock during release removal. |
| [`codex-release-store.ts`](../../src/cleaners/codex-release-store.ts)                             | Verifies manifests and release selections, and determines which older releases qualify.                                                       |
| [`discord-cleaner.ts`](../../src/cleaners/discord-cleaner.ts)                                     | Finds old Discord Squirrel versions and update remnants.                                                                                      |
| [`github-desktop-cleaner.ts`](../../src/cleaners/github-desktop-cleaner.ts)                       | Finds old GitHub Desktop Squirrel versions and downloads.                                                                                     |
| [`linua-cleaner.ts`](../../src/cleaners/linua-cleaner.ts)                                         | Checks known Linua updater locations for installers.                                                                                          |
| [`notion-cleaner.ts`](../../src/cleaners/notion-cleaner.ts)                                       | Finds downloaded and pending Notion installers.                                                                                               |
| [`npm-windows-housekeeper-toolkit.ts`](../../src/cleaners/npm-windows-housekeeper-toolkit.ts)     | Finds npm's downloaded package archives and metadata.                                                                                         |
| [`nuget-windows-housekeeper-toolkit.ts`](../../src/cleaners/nuget-windows-housekeeper-toolkit.ts) | Finds downloaded NuGet and Chocolatey archives.                                                                                               |
| [`nvidia-driver-cleaner.ts`](../../src/cleaners/nvidia-driver-cleaner.ts)                         | Finds downloaded and extracted installers and manages verified inactive display driver packages through Windows.                              |
| [`nvidia-driver-packages.ts`](../../src/cleaners/nvidia-driver-packages.ts)                       | Parses Driver Store output and identifies inactive packages older than the active display drivers.                                            |
| [`obsidian-cleaner.ts`](../../src/cleaners/obsidian-cleaner.ts)                                   | Finds Obsidian self-update installers.                                                                                                        |
| [`opencode-cleaner.ts`](../../src/cleaners/opencode-cleaner.ts)                                   | Finds verified OpenCode Desktop installer payloads and rechecks updater metadata before removal.                                              |
| [`signal-rgb-cleaner.ts`](../../src/cleaners/signal-rgb-cleaner.ts)                               | Finds old SignalRGB and VortxEngine versions and update payloads.                                                                             |
| [`slack-cleaner.ts`](../../src/cleaners/slack-cleaner.ts)                                         | Finds old Slack Squirrel versions and update remnants.                                                                                        |
| [`t3-code-cleaner.ts`](../../src/cleaners/t3-code-cleaner.ts)                                     | Finds downloaded and pending T3 Code installers.                                                                                              |
| [`vortex-cleaner.ts`](../../src/cleaners/vortex-cleaner.ts)                                       | Finds Vortex downloads in current and abandoned updater caches.                                                                               |
| [`vscode-cleaner.ts`](../../src/cleaners/vscode-cleaner.ts)                                       | Finds VS Code runtime and Chromium caches and downloaded extension archives.                                                                  |
